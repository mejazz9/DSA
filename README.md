## Repository Overview

The repository is organised by topic, with an emphasis on understanding underlying concepts, exploring different approaches, and improving solution efficiency.

It is intended to serve as both a record of my coding practice and a personal reference for revision.

### What You'll Find

- **Problem Solutions:** C++ implementations of DSA problems, organised by topic and difficulty.
- **Algorithmic Approaches:** Brute-force and optimised approaches, where applicable.
- **Complexity Analysis:** Time and space complexity considerations.
- **Concept Notes:** Important algorithms, C++ STL concepts, and recurring problem-solving patterns.
- **Revision & Insights:** Key observations, common mistakes, and concepts requiring further practice.

## Problem-Solving Methodology

My approach to solving problems focuses on:

1. **Understanding** the problem statement, constraints, and edge cases.
2. **Approaching** the problem with an initial solution before exploring optimisations.
3. **Implementing** efficient, readable solutions in C++.
4. **Analysing** time and space complexity.
5. **Revisiting** important patterns and previously challenging problems to reinforce understanding.
